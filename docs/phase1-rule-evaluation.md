# 阶段1规则改进与回归

日期：2026-09-12。基线为阶段0提交 `2dcc5f3`；比较对象为当前规则。原始文档不进入仓库。

## 行为变化

- 连续空段落合为一条 `fields.empty_paragraph`，保留起始 `paragraph_index` 和完整 `paragraph_indices`。单个留白默认 info，连续多个默认 warning；严重级别覆盖仍有效。实际 OOXML 兄弟节点保证跨表格不合并。图片、公式、分页和节分隔等承载段不算空段。
- 格式按角色、样式、正文/页眉页脚、表格及列分组，第一行与其他行分开。至少3段、主导格式严格过半才报告离群；这是保守规则，不代表小样本或无多数的内容已通过格式检查。
- 无Heading提示不再暗示文档没有视觉标题。Title/Subtitle样式或开头短段居中加粗可产生 `structure.title_candidate`，只是候选，不参与必需章节匹配或层级判断。
- 未审计对象保留逐个计数、XML路径，并增加所在表格/页眉页脚与附近文字。无法找到段落的对象仍保留包级定位；没有页码推断。

结果 schema 保持0.1，字段为向后兼容追加。但空段finding数量和默认严重级别有变化，依赖逐段数量的消费者需改用 `paragraph_indices`。原有定位测试改成验证一组及其所有索引；单空段受控标签从warning改为info。
