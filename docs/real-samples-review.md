# 真实文档复核记录与证据边界

更新日期：2026年9月15日。

## 审查发现

9月14日版本将10号正文连续空段、11号全部空单元格认定为确定缺陷，并声称完成逐项人工核验。这与9月9日保存的33页视觉记录不一致，而且没有逐项新证据支持改判。本轮撤回这些过强结论，不把它们用于真实文档准确率计算。

## 质量统计限制

12份文档仍没有完整的逐位置缺陷真值和独立复核一致性统计，故不计算整体Precision/Recall。程序提示减少不证明误报全消除，也不证明没有漏报。参考[阶段1回归](phase1-rule-evaluation.md)及[实验报告](experiment-report.md)。
